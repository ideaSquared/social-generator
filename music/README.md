# Music tracks

One audio file per brand, named after the brand exactly as the sheet writes it:

```
music/ideaSquared.mp3
music/AdoptDontShop.mp3
music/CreatrGrid.mp3
```

`.mp3`, `.m4a`, `.wav`, `.ogg` and `.flac` all work. See `docs/music.md` for what the tool does with them.

## Before you add a file here

This repository is public. Committing a track publishes it, so only commit a track whose licence lets anyone
copy and redistribute it. In practice that means CC0 (public domain dedication).

For every track committed here, add a line to the table below. Keep a track with any other licence out of git:
put it in another folder and set `MUSIC_DIR` to that folder.
