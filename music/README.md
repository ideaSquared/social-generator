# Music tracks

A small pool of tracks for each brand, in a folder named after the brand exactly as the sheet writes it:

```
music/ideaSquared/morning-coffee.mp3
music/AdoptDontShop/puppy-love.mp3
music/CreatrGrid/blue-skies.mp3
...
music/cuts.json
```

`.mp3`, `.m4a`, `.wav`, `.ogg` and `.flac` all work. `cuts.json` lists the clean places to start each track and is
written by `find_cuts.py`. See `docs/music.md` for what the tool does with all of this.

## Before you add a file here

This repository is public. Committing a track publishes it, so only commit a track whose licence lets anyone
copy and redistribute it. In practice that means CC0 (public domain dedication).

For every track committed here, add a line to the table below, then run `find_cuts.py`. Keep a track with any
other licence out of git: put it in another folder and set `MUSIC_DIR` to that folder.
